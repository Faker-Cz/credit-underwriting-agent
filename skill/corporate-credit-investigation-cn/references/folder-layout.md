# 文件夹与命名建议

## 推荐结构

```text
客户项目/
├─ 00_原始资料_只读/
│  ├─ 01_借款人/
│  ├─ 02_保证人/
│  ├─ 03_征信工商司法/
│  ├─ 04_上下游及合同/
│  ├─ 05_授信方案及政策/
│  └─ 06_参考模板/
├─ 01_材料清单与证据台账/
├─ 02_借款人财务数据/
├─ 03_保证人财务数据/
├─ 04_授信测算/
├─ 05_技术代码/
├─ 06_过程校验/
└─ 交付目录（由使用者自行指定）/
```

## 命名

建议使用不含机构名称的通用文件名，并由使用者自行指定保存位置。

不要在同一目录保留大量“初稿修改版_定点完善版_分页修正版_最终版”等难以辨认的文件。用户明确要求清理时，保留：

1. 用户指定原始/手工修改基准版；
2. 当前最新版；
3. 必要的财务底稿和测算表；
4. 一份历史备份。

删除前先列清单确认；技术代码删除也必须得到明确要求。

## 技术代码

可集中放在`05_技术代码`，中文命名并附README说明用途。`chi_sim.traineddata`和`eng.traineddata`属于OCR运行依赖，可以放在`05_技术代码/OCR语言包`，但不应混进最终报告目录。
