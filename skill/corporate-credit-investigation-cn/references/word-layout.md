# Word模板定点补充与格式保护

## 1. 基准文件

- 用户指定文件是唯一基准。
- 原文件只读，输出新文件。
- 修改前统计段落、表格、图片、节、页眉页脚和页数；修改后做对比。
- 不整篇复制到新文档，不重建模板样式。
- 默认模板为使用者在本地私下提供并获授权的`../assets/授信报告模版-skill.docx`，不再使用2018版标准空白模板；该Word文件不得提交到公开仓库。

## 2. 定点修改

只允许：

1. 在现有段落的既定填写位置补充或替换文字；
2. 在现有单元格或内容控件的既定填写位置补充或替换内容；
3. 保留目标位置原有段落属性和字符属性，让新文字继承插入点既有格式。

不得新增、删除、复制、移动或重排段落、表格、图片、文本框、分页符、分节符或其他文档结构，也不得整段清空后重建。

不要用全文查找替换企业简称，避免误改模板标题、页眉、引用或其他公司名称。

- 复选项只在模板已有Word原生复选框内容控件内切换状态，选中显示“☑”（U+2611），不得以普通字符重建复选框或改变其格式。
- 封面字段只替换原有填写值，保留标签与值的分段、连续下划线、前后空格、缩进、行距和对齐方式，不得清空整段后重建。

## 3. 排版、表格、字体和分页

- 模板当前状态就是唯一标准，不按任何预设规则重新设置标题、正文、表格或封面格式。
- 不改动字体、字号、字重、颜色、段落样式、缩进、制表位、行距、段前段后距、对齐、边框、底纹、表格结构、合并关系、行高、列宽、文字方向、自动调整、页边距、纸张、页眉页脚、页码、分节和分页属性。
- 不清理空段落、手工分页符或分节符，不修复标题孤行、跨页、整页空白、竖排字符、数字换行或对象位置。
- 若补充内容导致溢出、分页变化或其他显示问题，保留模板格式并在交付说明中报告；除非用户另行明确授权，不得通过缩字、调距、改表格、移动内容或重排版解决。
- 每次交付均在模板基础上另存一份新文件，不覆盖标准模板或用户原件。

## 4. 渲染验证

使用文档工具的渲染流程把DOCX转为逐页PNG或PDF：

1. 先检查页数是否异常骤减或骤增；
2. 逐页看标题、表格、页眉页脚、页码和空白；
3. 对新增或修改页放大检查数字是否截断；
4. 对新增或修改页重点复核；
5. 发现问题时记录并报告，不改动模板格式；只有用户另行明确授权格式修改后，才可定点处理并重新渲染。

没有完成逐页渲染检查时，不得对用户说“格式已经全部检查无误”。
