# 低风险／无风险授信报告写作规范

本文件只规定低风险／无风险报告相对于一般授信的“分析深度差异”。事实核验、客户经理口吻、重点栏目逻辑和模板权限分别继承`evidence-and-materials.md`、`report-writing.md`、`core-section-writing.md`和`word-layout.md`；本文件不重复创造另一套事实或格式规则。

低风险／无风险报告默认从`../assets/低风险报告模版.docx`只读复制后另存项目文件；不得使用一般单一客户模板推定低风险报告结构。用户本轮指定其他最新版时，以用户指定文件优先。

## 1. 适用范围与目标

本规范适用于用户明确称为“低风险报告”“无风险报告”，或授信方案主要由本行认可的低风险缓释措施足额覆盖、模板本身要求简明分析的项目。

客户经理口吻是全部授信报告的统一底层文风，不是低风险报告的专属风格。本规范只负责在统一文风基础上调整低风险报告的篇幅、指标数量、栏目取舍和风险展开深度；一般授信和高风险／复杂项目仍保持客户经理口吻，但分析更充分。

目标不是简单减少字数，而是在客户经理式授信分析的基础上进一步突出核心判断：

- 事实准确，主体、期间、单位和方案一致；
- 用业务语言说明企业实际做什么、为什么变化、靠什么赚钱和还款；
- 判断明确，整体基调积极但不粉饰；
- 只保留会影响审批判断的实质信息；
- 核验过程、逐项勾稽和一般性贷后动作留在工作底稿；
- 不为填满栏目虚构缓释物、资产、经营动作或管理措施。

低风险只影响报告的篇幅、重点和风险展开程度，不降低事实核验标准，不等于所有风险均可省略。

## 2. 写作模式选择

动笔前必须先确定模式：

| 判断事项 | 低风险／无风险模式 | 一般或高风险模式 |
|---|---|---|
| 分析目标 | 讲清业务、还款和低风险保障，简洁支持授信 | 全面论证经营、财务、担保和风险条件 |
| 行业表述 | 按模板和审批需要写核心国标行业名称即可 | 可写三级路径、代码及竞争分析 |
| 财务分析 | 核心趋势、关键数据、经营原因、授信判断 | 重要科目桥接、现金流、融资和压力分析 |
| 风险事项 | 只写实质风险及其影响 | 写风险成因、传导、缓释和触发条件 |
| 核验过程 | 留在底稿 | 重大口径差异可进入正文 |
| 不适用栏目 | 直接填“无”或“不适用” | 仍按实际事实填写，不用模板说明代替事实 |

若用户的具体要求与模式默认值不同，以用户要求为准。不得因客户看似低风险而自行降低分析深度；也不得因模板栏目较多而自动采用重风险写法。

## 3. 不可突破的准确性边界

### 3.1 当前信息优先

- 法定代表人、股东、实际控制人、高管、注册资本、经营范围和风险信息采用报告基准日可验证的最新状态。
- 历史材料与当前工商信息冲突时，正文写当前状态；确有必要再简述变更时间和历史状态。
- 法定代表人、控股股东、实际控制人和最终受益人分别核实、分别填写，禁止因法人变更而推定实际控制人变化。

### 3.2 正面表达必须有依据

- “经营修复”“主动调整”“客户稳定”“已妥善处理”“偿债能力较强”等判断必须由数据、合同、回款、工商或用户确认支持。
- 亏损转盈利必须核对年度。若2023年亏损、2024年盈利，应写“2024年实现扭亏”，不得因截图或参考文本的语气更顺而沿用错误年份。
- “净资产收益率保持理想水平”“不存在影响经营的事项”等结论必须有可验证指标或材料，不能作为积极语气模板自动生成。

### 3.3 参考报告只学结构与表达

参考报告、截图和历史客户报告只用于学习章节组织、表达取舍和版式，不得复制其中客户名称、人员、行业、经营事实、财务数字、风险事件或缓释措施。

## 4. 客户经理式表达框架

低风险模式的自然段优先采用：

> 判断＋关键事实或数据＋经营原因＋对授信／还款的意义

通常一至三句即可。只有出现重大异常时，才增加核验事项或缓释条件。

推荐语气：

- “公司主要从事……，在集团内承担……职能，收入主要来自……。”
- “受外部消费环境影响，公司适度收窄经营规模，同时优化商品结构并将资源集中于盈利能力较好的产品，盈利水平逐步修复。”
- “报告期内公司实现扭亏，资产负债率下降，经营现金流改善，财务结构趋于稳健。”实际使用时必须替换为目标客户对应年度和经核实趋势。
- “现有案件金额较小且已处理／处于正常程序，对持续经营和本次授信影响有限。”前提是状态有材料支持。

不推荐语气：

- “经逐笔核验、穿透核查、逐分勾稽……”
- “须核清、应重点关注、持续监测、风险总体可管理。”
- “可以通过履行、和解或司法裁判解决。”
- “后续留存材料即可持续更新风险状态。”
- 在每个正常经营事实后机械追加“但仍需关注……”。

## 5. 各栏目写法

### 5.1 行业

- 低风险报告按模板需要填写核心国标行业名称；用户要求简写时，不追加无助于判断的多级路径、行业代码、英文代码或平台分类说明。
- 一般授信或模板明确要求行业层级时，才使用`大类>中类>小类`格式。
- 工商平台行业分类只是线索，应与主要收入和实际业务核对；不能因营业执照经营范围很宽而堆列多个行业。

### 5.2 企业实际做什么

必须用一至两句话回答：

1. 销售或提供什么产品／服务；
2. 服务哪些客户或集团内部主体；
3. 在集团或业务链条中承担什么职能；
4. 主要通过什么方式形成收入和回款。

禁止只写“平台运营、产品销售、技术服务”等抽象标签。企业存在多项业务或承担集团内部职能时，应说明每项业务的具体内容、服务对象、收入来源和回款路径，形成完整业务画像。

### 5.3 经营变化原因

出现收入下降、规模收缩、毛利改善或费用下降时，应同时考虑：

- 外部环境：疫情、消费能力、市场需求、渠道变化、行业竞争；
- 管理层主动动作：收窄规模、优化商品结构、退出低毛利业务、集中资源、控制费用、改善周转。

写作重点是解释管理层如何应对，而不是把收入下降直接等同于经营恶化。没有材料支持“主动调整”时不得自行添加，可用用户说明、管理层访谈、产品结构或费用变化进行交叉验证。

### 5.4 盈利模式

用审批人容易理解的业务语言说明“靠什么赚钱”，不写教科书式利润公式。

例如可概括为“利润主要来自核心产品销售及配套服务费”，但必须使用目标客户实际产品和服务名称改写。

仅在毛利率异常或需要解释价格传导时，才进一步分析目标客户实际成本驱动因素；平台费用、广告推广、履约费用等只适用于材料证明存在相应业务的企业。

### 5.5 销售渠道、客户和供应商

- 用关键数据支持集中度判断，例如主要客户或渠道的销售额和占比；仅在目标客户实际依赖平台渠道时分析主要平台占比。
- 正文保留足以支持判断的金额和占比即可。
- 含税口径、支付流水、跨主体或跨渠道归集、重复计算排查等属于核验底稿；只有差异重大并会影响收入真实性或还款判断时才进入报告。
- 不在正常渠道集中事实后自动增加“投放前须核查全部流水”等条件。

### 5.6 财务分析

低风险报告按以下顺序写：

1. 总体趋势：盈利是否修复、结构是否优化、经营是否稳定；
2. 核心指标：收入、净利润、资产负债率、流动比率、现金流、刚性负债；
3. 经营原因：外部环境、主动收缩、产品结构、回款周期、备货和资金周转；
4. 授信判断：盈利、现金回笼和偿债基础是否与申请额度匹配。

推荐按“报告期总体趋势—关键指标及实际年度—经营原因—与申请额度和低风险保障的关系”组织。不得复用固定年份、固定趋势或“能够支持本次业务”等结论，必须按目标客户数据重新判断。

最终报告不应塞入：

- 全科目逐项复述；
- 受限资金逐分勾稽过程；
- 每一处附注核对过程；
- 所有同比、占比和公式；
- 流动资金测算的中间公式；
- 与低风险方案无关的完整压力测试；
- 同一缓释措施在财务、融资、担保和综合判断中反复说明。

### 5.7 融资和或有负债

- 有余额时填机构数、余额、期限和分类等审批所需信息，并作一段简短判断。
- 无融资、无对外担保、无逾期或无或有负债时，直接填“无”。
- 不为“无”扩写假设性风险、未来融资计划或通用贷后动作。
- 低风险业务不等于可以省略已存在的大额融资、异常分类或高额对外担保；此类事项仍应如实写明。

### 5.8 司法和行政处罚

正文写清：

- 案件或处罚数量；
- 涉及金额；
- 原告／被告或处罚事由；
- 当前处理状态；
- 是否对经营和本次授信形成实质影响。

没有相关事项直接写“无”。不扩写“可以通过履行、和解、司法裁判解决”等一般法律常识，也不代企业安排整改或贷后动作。

若仅有平台统计而没有处理结果，不得写“已处理完毕”；可写已核实的状态，并把详细文书核查留在底稿或集中缺口清单。

### 5.9 缓释物和不适用栏目

- 先判断正式方案是否实际采用保证、抵押、质押、存单、票据、现金、冻结或资产池。
- 不适用时直接填“无”或“不适用”。
- 模板中的“如为银行承兑汇票质押，应关注银行资信”等文字属于填写说明，不是客户事实，不能保留为本案分析。
- 不得根据模板说明自行创造现金、存单、质押、冻结、处置安排或第二还款来源。
- 只有正式方案明确采用某项缓释措施时，才分析缓释物权属、价值、控制方式、处置和覆盖程度。

### 5.10 综合评价

低风险综合评价回答四个问题：

1. 客户经营是否真实、稳定；
2. 本次业务需求是否合理；
3. 第一还款来源是否清楚；
4. 低风险保障是否真实、足额、可控制。

结论以支持理由为主，重大风险简要提示一次即可。不得把前文全部财务、融资、司法和缓释内容再次复制。

## 6. 工作底稿与最终报告的边界

### 留在工作底稿

- 财务逐项勾稽和公式；
- 发票、支付流水和销售渠道重复性排查；
- 受限资金逐笔核对；
- 企查查页面逐项截图；
- 正常且金额较小事项的完整核验过程；
- 通用贷后建议和模板填报说明；
- 不影响最终额度的测算中间值。

### 应进入最终报告

- 影响客户身份、控制关系、业务真实性、收入利润和偿债能力的事实；
- 影响额度、期限、品种、资金用途和缓释有效性的结论；
- 重大融资、担保、诉讼、处罚、逾期、受限资产和口径差异；
- 需要审批人据此设置条件的重大缺口。

判断标准：删除该核验过程后，审批人能否仍然理解客户为什么值得授信、如何还款、低风险保障是否有效。若能，则核验过程原则上不进入正文。

## 7. 语言压缩与去机器化

### 删除或改写的高频句式

- “数据显示”“总体来看”：能直接陈述事实时删除。
- “具备一定实力”“发展前景较好”：改为具体收入、利润、客户或现金数据。
- “须核清”“应重点关注”“持续监测”：仅用于确有重大异常并需要明确动作的事项。
- “风险总体可管理”：改为说明具体缓释覆盖、正常分类、回款来源或金额影响。
- “现有资料未披露，本报告不作分析”：先查询公开资料；仍无法确认且不影响审批时删除，影响审批时集中列入缺口清单。

### 控制重复

同一事实只在最能支撑判断的位置详细分析一次：

- 低风险保障在方案或缓释章节详细写，综合评价只作结论；
- 财务趋势在财务章节写，综合评价只引用结论；
- 司法事件在风险章节写，不在每个经营段落重复；
- 资金用途和还款来源分别写业务用途与现金来源，不互相复制。

## 8. 低风险报告质量门

交付前逐项检查：

1. 是否先识别了低风险／无风险模式，而不是套用一般授信长报告写法；
2. 是否用一至两句话说清企业实际业务和集团职能；
3. 法定代表人、实际控制人和股东是否分别核实且为当前信息；
4. 行业是否按本案要求简写，未无意义堆列代码和多级路径；
5. 收入下降或利润改善是否同时解释外部因素和企业主动调整；
6. 盈利模式是否使用业务语言；
7. 财务分析是否形成“趋势＋数据＋原因＋授信判断”；
8. 是否删除了逐笔核验、逐分勾稽和公式推导过程；
9. 融资、或有负债、司法和处罚是否有则简写、无则填“无”；
10. 不适用缓释栏目是否直接填“无／不适用”，未沿用模板说明或虚构措施；
11. 是否存在无依据的“已处理、盈利理想、偿债能力强”等积极结论；
12. 重大风险是否仍被如实保留，并且没有因低风险模式被删除；
13. 同一风险或缓释是否在多个章节重复；
14. 是否在全部报告通用的客户经理口吻基础上保持简洁，未退化为机器审计记录或合规检查清单；
15. 所有年份、金额、占比、身份和结论是否与原始材料一致。

## 9. 最终原则

> 学习用户的表达风格和信息取舍，不复制个案事实；正面表达必须建立在准确数据上，简洁不等于省略重大风险，低风险也不等于虚构缓释措施。

低风险报告的优秀标准不是“写得最少”，而是让审批人在较短篇幅内迅速看清：客户是谁、实际做什么、为什么发生变化、靠什么盈利和还款、本次低风险保障如何成立，以及是否存在会改变授信判断的重大事项。
