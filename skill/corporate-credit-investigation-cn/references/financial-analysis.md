# 财务数据与财务分析

## 1. 三表汇总的硬性要求

- 资产负债表、利润表、现金流量表必须覆盖来源报表出现的全部科目，包括空行层级和其中项。
- 列顺序通常为2023年末、2024年末、2025年末、最新一期；利润表和现金流量表注明年度/累计期间。
- 某期无数据用空白或“—”，不得用0代替未知。
- 用户要求“纯数值”时，数据单元格保存为数值常量，不留公式、文本数字或单位字符。
- 负数保留负号；括号数按负数处理；不擅自取绝对值。

## 2. 单位换算

建立三层数据：

1. 原始层：保留PDF或Excel原单位和原始值；
2. 展示层：财务表格通常用万元；
3. 分析层：正文优先用亿元并保留两位小数。

换算关系：

- 元转万元：除以10,000；
- 元转亿元：除以100,000,000；
- 万元转亿元：除以10,000。

不得仅改变单元格显示格式而未换算实际数值。每个工作表显著标注单位。

## 3. 资产负债表衍生列

以C列前年末、D列上年末、E列即期为例：

- 上年末比前年增减：`(D5-C5)/C5`
- 上年末各项占比：`D5/$D$总计行`
- 即期各项占比：`E5/$E$总计行`

资产项目以总资产为分母，负债项目以负债合计为分母，所有者权益项目以所有者权益合计为分母。分母为0或空白时留空，不显示除零错误。

## 4. 报表勾稽

### 资产负债表

- 资产总计 = 负债和所有者权益总计；
- 流动资产合计和非流动资产合计与明细求和一致；
- 流动负债、非流动负债、所有者权益合计与明细一致；
- 上年期末数与次年期初数一致，若审计重述则记录差异。

### 利润表

按报表列示层级验证，不把“其中”项目重复计入：

- 营业利润 = 营业收入 − 营业成本 − 税金及附加 − 销售费用 − 管理费用 − 研发费用 − 财务费用 + 其他收益 + 投资收益 + 公允价值变动收益 + 信用减值损失 + 资产减值损失 + 资产处置收益；
- 利润总额 = 营业利润 + 营业外收入 − 营业外支出；
- 净利润 = 利润总额 − 所得税费用；
- 归母净利润 + 少数股东损益 = 合并净利润（适用时）。

注意报表中“损失以‘-’号填列”的项目已经自带符号，公式中应按列示符号相加，避免二次取反。

### 现金流量表

- 经营、投资、筹资活动净额分别等于各自流入小计减流出小计；
- 现金及现金等价物净增加额与三类净额及汇率影响相符；
- 期末现金及现金等价物余额 = 期初余额 + 净增加额；
- 与资产负债表货币资金差异应能由其他货币资金、受限资金或现金等价物口径解释。

## 5. 常用财务指标

### 偿债能力

- 资产负债率 = 总负债 / 总资产；
- 流动比率 = 流动资产 / 流动负债；
- 速动比率 =（流动资产 − 存货 − 预付款项等低速动项目）/ 流动负债，按模板口径固定；
- 现金比率 = 货币资金 / 流动负债；
- 有息负债/净资产 = 有息负债 / 净资产；
- 经营活动现金净流量/财务费用。

### 营运能力

- 应收账款周转率 = 营业收入 / 平均应收账款；
- 存货周转率 = 营业成本 / 平均存货；
- 总资产周转率 = 营业收入 / 平均总资产。

### 盈利能力

- 销售毛利率 =（营业收入 − 营业成本）/ 营业收入；
- 销售净利率 = 净利润 / 营业收入；
- 资产净利率 = 净利润 / 平均总资产；
- 净资产收益率 = 净利润 / 平均净资产。

### 成长能力

- 营业收入增长率；
- 净利润增长率；
- 资本增值率 = 期末所有者权益 / 期初所有者权益 − 1。

跨期损益指标需要年化时必须注明；亏损转盈利时不机械给出失真的增长率，改写为“实现扭亏”。

## 6. 重要风险指标怎么写

风险指标不是把所有比率堆在一行，而是解释异常值。建议包括：

1. 是否跨行业、跨产业链投资；
2. 上年末刚性负债结构及业务原因；
3. 经营现金净流量对财务费用覆盖；
4. 即期资产负债率和有息负债变化及科目去向；
5. 流动、速动和经营现金流的阶段性变化。

示例分析逻辑：

“2026年4月末有息负债较2025年末增加4.44亿元。资金端增加主要体现为短期借款、一年内到期长期融资和新增长期借款；资产端同期预付款、存货和固定资产分别增加，分别对应已支付待到货设备款、回收业务备货及已投放租赁设备。由此看，本轮负债增长主要服务于采购和资产投放，具有重资产租赁业务的经营特征。”

## 7. 资产科目分析

每个重点科目写四件事：金额趋势、占比、具体构成、业务含义。

- 货币资金：如附注明确，拆分存款和其他货币资金；不猜测活期、大额存单或受限性质。
- 应收账款：结合账龄、客户集中度、信用政策和回款；期末余额不能替代年度销售额。
- 预付款项：结合设备采购、供应链付款节点和期后到货。
- 存货：区分待售回收设备、备品备件、在途设备等（仅在明细支持时）。
- 固定资产：结合租赁设备类别、原值、折旧、出租和更新。
- 长期股权投资：区分合并范围内投资与联营/合营投资。

“权利受限”列只有在存在抵押、质押、冻结、融资租赁权属安排或其他限制时才填写；无明确限制的注册地、办公地址等不应被误写为权利受限。

## 8. 负债和有息负债分析

统一有息负债口径，至少列明：短期借款、一年内到期的非流动负债、长期借款、长期应付款/融资租赁，以及是否纳入租赁负债。

分析2023—最新一期连续变化，而非只比较最近两期：

- 规模增长是否连续；
- 短期和长期结构是否变化；
- 新增负债投向哪些资产；
- 财务费用与平均有息负债是否匹配；
- 经营现金流和资产处置现金流能否支撑周转。

## 9. 盈利和现金流分析

- 收入增长要拆业务：高毛利租赁与低毛利回收分别看规模、占比和毛利率。
- 扭亏要解释来自毛利改善、费用控制、其他收益还是资产处置，不能只写净利润增加。
- 经营现金流转负时，分解销售回款、采购支付、税费和其他经营收支，并联系预付款、存货和应付款变化。
- 对扩张期现金流，明确“现金先投入—设备投放/存货销售—租金或销售回款”的时间差，不使用无条件的“有望转化”。

## 10. 流动资金需求测算

按用户指定模板公式，不另创口径。常见步骤：

1. 取2024—2025年应收、预付、存货、应付、预收/合同负债平均余额；
2. 计算周转天数；
3. 营运资金周转周期 = 应收天数 + 预付天数 + 存货天数 − 应付天数 − 预收天数；
4. 周转次数 = 360 / 周转周期；
5. 基础营运资金量 = 营业成本或模板规定基数 / 周转次数；
6. 按模板扣减自有资金、现有流贷等，得出新增流动资金贷款额度。

工作簿中的两个工作表视为同一测算模板的两个实例：已填工作表用于识别数据位置和样式，空白工作表用于核对公式和输入区域。后续编制时：

1. 两个工作表都保留，不删表、不改表名、不重排结构；
2. 将已填样例中的客户数据替换为目标公司的对应财务数据，不得沿用样例企业数值；
3. 两个工作表的对应输入项均同步填入目标公司数据，差异字段按各自现有模板设置填写；
4. 只改黄色或明确的输入区域，保留公式、颜色、边框、保护和锁定区域；
5. 两个工作表都必须完整呈现最终“新增流动资金贷款额度”，不能只计算中间过程；
6. 分别检查公式错误、单位、年份、增长率、周转次数和最终额度，并把采用的测算结果写入授信方案合规性评价。

当前模板关键输入通常包括：应收账款、预付账款、存货、应付账款、预收账款、主营业务收入、主营业务成本、净利润、预计销售收入增长率、现有自有资金、现有流动资金贷款、其他渠道营运资金、调节系数及特定需求。数据取值必须服从工作表自身行名和期间口径。

## 11. 错误升级复核

发现以下任一问题时全量复核：

- 单位少/多一位；
- OCR多识别或漏识别一位数字；
- 文本数字、公式残留；
- 同科目前后期错位；
- 负号错误；
- 现金流项目错行；
- 利润表勾稽不平；
- 资产负债表不平。

复核范围包括全部年份、全部科目、所有合计、所有同比占比和报告正文引用。
