# 财务数据与财务分析

## 1. 三表汇总的硬性要求

- 资产负债表、利润表、现金流量表必须覆盖来源报表出现的全部科目，包括空行层级和其中项。
- 列顺序通常为最近三个完整年度末及最新一期；利润表和现金流量表注明年度/累计期间。
- 某期无数据用空白或“—”，不得用0代替未知。
- 用户要求“纯数值”时，数据单元格保存为数值常量，不留公式、文本数字或单位字符。
- 负数保留负号；括号数按负数处理；不擅自取绝对值。

### 保证人三表动态列结构

- 原则上采用“最近三年＋最新一期”，具体年度及月末/累计期间按报告基准日、实际材料和用户模板动态生成，不把某个项目的2023—2026年4月末固化为全局期间。
- 资产负债表：`资产负债表科目｜前两年｜上一年｜最近年度｜最新期末｜上一年较前两年变动｜最近年度较上一年变动｜最近年度各项占比｜最新一期各项占比`。
- 利润表：`利润表科目｜前两年｜上一年｜最近年度｜最新累计期间｜上一年较前两年变动｜最近年度较上一年变动｜最近年度各项占比｜最新一期各项占比`。
- 现金流量表：`现金流量表科目｜前两年｜上一年｜最近年度｜最新累计期间｜上一年较前两年变动｜最近年度较上一年变动`。
- 例如报告基准日为2026年4月且材料齐全时，可实例化为2023年、2024年、2025年、2026年4月末/1—4月；换一家公司或基准日后必须同步更换表头和变动列名称。
- 年度与即期金额列只显示万元金额；“较上年变动”列只显示百分比，如`93.72%`或`-100.00%`，不得显示`1,373.18（—）`、`0.00（—）`等“金额（比例）”组合。
- 分母为0、上期为空或无法形成有意义比例时填`—`；不得用0.00%替代无法计算，也不得把本期金额重复写入变动列。
- 资产负债表占比按资产、负债、所有者权益各自合计为分母；利润表占比按营业收入或模板指定基数计算；现金流量表不强制增加占比列。
- 利润表和现金流量表的最新一期为累计发生额，必须注明`1—N月`；趋势分析优先与上年同期比较，不把四个月、半年或九个月累计数直接与上一完整年度计算同比。模板只有全年变动列时，年度变动仍按完整年度计算，最新一期只作规模、结构或经年化且明确标注的辅助判断。

## 2. 单位换算

建立三层数据：

1. 原始层：保留PDF或Excel原单位和原始值；
2. 展示层：财务表格通常用万元；
3. 分析层：正文优先用亿元并保留两位小数。

换算关系：

- 元转万元：除以10,000；
- 元转亿元：除以100,000,000；
- 万元转亿元：除以10,000。

不得仅改变单元格显示格式而未换算实际数值。每个工作表显著标注单位。

正文叙述中的金额达到1亿元及以上时，原则上统一换算为亿元并保留两位小数，如`6.23亿元`；不足1亿元或需要与表格精确勾稽时使用万元。表格继续按模板单位展示，不因正文换算改变底层数据。

## 3. 资产负债表衍生列

以C列前年末、D列上年末、E列即期为例：

- 上年末比前年增减：`(D5-C5)/C5`
- 上年末各项占比：`D5/$D$总计行`
- 即期各项占比：`E5/$E$总计行`

资产项目以总资产为分母，负债项目以负债合计为分母，所有者权益项目以所有者权益合计为分母。分母为0或空白时留空，不显示除零错误。

## 4. 报表勾稽

### 资产负债表

- 资产总计 = 负债和所有者权益总计；
- 流动资产合计和非流动资产合计与明细求和一致；
- 流动负债、非流动负债、所有者权益合计与明细一致；
- 上年期末数与次年期初数一致，若审计重述则记录差异。

### 利润表

按报表列示层级验证，不把“其中”项目重复计入：

- 营业利润 = 营业收入 − 营业成本 − 税金及附加 − 销售费用 − 管理费用 − 研发费用 − 财务费用 + 其他收益 + 投资收益 + 公允价值变动收益 + 信用减值损失 + 资产减值损失 + 资产处置收益；
- 利润总额 = 营业利润 + 营业外收入 − 营业外支出；
- 净利润 = 利润总额 − 所得税费用；
- 归母净利润 + 少数股东损益 = 合并净利润（适用时）。

注意报表中“损失以‘-’号填列”的项目已经自带符号，公式中应按列示符号相加，避免二次取反。

### 现金流量表

- 经营、投资、筹资活动净额分别等于各自流入小计减流出小计；
- 现金及现金等价物净增加额与三类净额及汇率影响相符；
- 期末现金及现金等价物余额 = 期初余额 + 净增加额；
- 与资产负债表货币资金差异应能由其他货币资金、受限资金或现金等价物口径解释。

## 5. 常用财务指标

### 偿债能力

- 资产负债率 = 总负债 / 总资产；
- 流动比率 = 流动资产 / 流动负债；
- 速动比率 =（流动资产 − 存货 − 预付款项等低速动项目）/ 流动负债，按模板口径固定；
- 现金比率 = 货币资金 / 流动负债；
- 有息负债/净资产 = 有息负债 / 净资产；
- 经营活动现金净流量/财务费用。

### 营运能力

- 应收账款周转率 = 营业收入 / 平均应收账款；
- 存货周转率 = 营业成本 / 平均存货；
- 总资产周转率 = 营业收入 / 平均总资产。

### 盈利能力

- 销售毛利率 =（营业收入 − 营业成本）/ 营业收入；
- 销售净利率 = 净利润 / 营业收入；
- 资产净利率 = 净利润 / 平均总资产；
- 净资产收益率 = 净利润 / 平均净资产。

### 成长能力

- 营业收入增长率；
- 净利润增长率；
- 资本增值率 = 期末所有者权益 / 期初所有者权益 − 1。

跨期损益指标需要年化时必须注明；亏损转盈利时不机械给出失真的增长率，改写为“实现扭亏”。

未经审计的最新一期与经审计年度数据并列时，在表头或必要的口径说明中标明审计属性；业绩预告、快报和管理口径数据不得替代正式定期报告或审计数据，必须分别注明性质。

## 6. 重要风险指标怎么写

风险指标不是把所有比率堆在一行，而是解释异常值。建议包括：

1. 是否跨行业、跨产业链投资；
2. 上年末刚性负债结构及业务原因；
3. 经营现金净流量对财务费用覆盖；
4. 即期资产负债率和有息负债变化及科目去向；
5. 流动、速动和经营现金流的阶段性变化。

分析逻辑：先量化有息负债变化及短长结构，再追踪资金在货币资金、应收、预付款、存货、固定资产、在建工程或其他经营资产中的去向，最后根据目标客户实际业务判断新增融资是支持生产采购、贸易周转、项目垫资、服务交付或资产投放，还是用于弥补长期亏损。不得套用参考客户的设备回收、算力或租赁结论。

没有真实异常或跨行业投资时直接填“无”或“否”，不为填满栏目扩写假设性风险。正常的采购、备货、账期或投放波动应解释其经营用途和合理性，不机械转写为风险提示。

## 7. 资产科目分析

每个重点科目写四件事：金额趋势、占比、具体构成、业务含义。

- 货币资金：如附注明确，拆分银行存款和其他货币资金；不猜测活期、大额存单或受限性质。
- 应收账款：结合账龄、客户集中度、信用政策和回款；期末余额不能替代年度销售额。
- 预付款项：结合设备采购、供应链付款节点和期后到货。
- 存货：按实际明细区分原材料、在产品、库存商品、合同履约成本、周转材料或在途物资，分析库龄、跌价、周转和订单对应关系。
- 固定资产：结合实际资产类别、原值、折旧、产能/使用效率、权属和更新投入；租赁资产或经营性设备仅在客户确属该模式时分析出租和残值退出。
- 长期股权投资：区分合并范围内投资与联营/合营投资。

“权利受限”列只有在存在抵押、质押、冻结、融资租赁权属安排或其他限制时才填写；无明确限制的注册地、办公地址等不应被误写为权利受限。

## 8. 负债和有息负债分析

统一有息负债口径，至少列明：短期借款、一年内到期的非流动负债、长期借款、长期应付款/融资租赁，以及是否纳入租赁负债。

分析2023—最新一期连续变化，而非只比较最近两期：

- 规模增长是否连续；
- 短期和长期结构是否变化；
- 新增负债投向哪些资产；
- 财务费用与平均有息负债是否匹配；
- 经营现金流和资产处置现金流能否支撑周转。

## 9. 盈利和现金流分析

- 收入增长要拆业务：高毛利租赁与低毛利回收分别看规模、占比和毛利率。
- 扭亏要解释来自毛利改善、费用控制、其他收益还是资产处置，不能只写净利润增加。
- 经营现金流转负时，分解销售回款、采购支付、税费和其他经营收支，并联系预付款、存货和应付款变化。
- 对扩张期现金流，按行业明确“现金投入—采购/生产/项目实施/资产投放—交付或销售—经营回款”的时间差，不使用无条件的“有望转化”。

### 所有报告通用的客户经理式财务表达

- 最终正文均按“总体判断—关键数据—业务原因—对回款、偿债或授信的意义”组织，不因报告风险等级不同而改变客户经理视角。
- 财务数据必须先在底稿完成全科目、跨表和跨期核验；正文只呈现支持判断所需的核验结果，不复述核验动作和公式过程。
- 一般授信应充分解释重要科目、资产负债形成、现金流和融资变化；高风险／复杂项目进一步分析风险传导、压力情景和触发条件。上述分析仍使用业务语言，不写成审计底稿或检查清单。
- 正常经营事实后不机械追加“应重点关注、持续监测”；只有实质风险会改变授信判断或方案条件时，才量化说明影响并提出可执行管控。

### 低风险／无风险报告的正文取舍

- 最终正文采用“总体趋势＋关键指标＋经营原因＋授信判断”，优先选取营业收入、净利润、资产负债率、流动比率、经营现金流和刚性负债等能够直接支持经营与偿债判断的指标。
- 收入下降不能只写“经营规模收缩”；有依据时同时说明疫情、消费能力、需求变化等外部影响，以及收窄规模、优化商品结构、集中高利润产品、控制费用等主动调整。
- 利润来源使用业务语言，例如商品销售利润和软件技术服务费，不在非必要情况下写成销售价减采购成本、平台费、广告费和履约费的教科书公式。
- 逐分勾稽、全科目复述、附注核验过程、支付流水排重和测算中间公式留在底稿；只有会改变收入真实性、偿债判断或授信方案的重大差异才进入正文。
- 亏损转盈利必须核准年度并写“某年实现扭亏”；零基数、负转正或正转负不输出失真增长率。

## 10. 流动资金需求测算

按用户指定模板公式，不另创口径。常见步骤：

1. 取最近两个完整年度的应收、预付、存货、应付、预收/合同负债平均余额；
2. 计算周转天数；
3. 营运资金周转周期 = 应收天数 + 预付天数 + 存货天数 − 应付天数 − 预收天数；
4. 周转次数 = 360 / 周转周期；
5. 基础营运资金量 = 营业成本或模板规定基数 / 周转次数；
6. 按模板扣减自有资金、现有流贷等，得出新增流动资金贷款额度。

工作簿中的两个工作表视为同一测算模板的两个实例：已填工作表用于识别数据位置和样式，空白工作表用于核对公式和输入区域。后续编制时：

1. 两个工作表都保留，不删表、不改表名、不重排结构；
2. 将已填样例中的客户数据替换为目标公司的对应财务数据，不得沿用样例企业数值；
3. 两个工作表的对应输入项均同步填入目标公司数据，差异字段按各自现有模板设置填写；
4. 只改黄色或明确的输入区域，保留公式、颜色、边框、保护和锁定区域；
5. 两个工作表都必须完整呈现最终“新增流动资金贷款额度”，不能只计算中间过程；
6. 分别检查公式错误、单位、年份、增长率、周转次数和最终额度，并把采用的测算结果写入授信方案合规性评价。

当前模板关键输入通常包括：应收账款、预付账款、存货、应付账款、预收账款、主营业务收入、主营业务成本、净利润、预计销售收入增长率、现有自有资金、现有流动资金贷款、其他渠道营运资金、调节系数及特定需求。数据取值必须服从工作表自身行名和期间口径。

测算工作簿如按模板必须展示基础测算、特定需求和调整过程，应完整保留这些单元格；最终报告的文字分析以最终有效结果为比较基准，不把基础测算为0或负数误写成最终额度。不得以“正文简化”为由篡改或隐藏模板要求保留的测算字段。

## 11. 错误升级复核

发现以下任一问题时全量复核：

- 单位少/多一位；
- OCR多识别或漏识别一位数字；
- 文本数字、公式残留；
- 同科目前后期错位；
- 负号错误；
- 现金流项目错行；
- 利润表勾稽不平；
- 资产负债表不平。

复核范围包括全部年份、全部科目、所有合计、所有同比占比和报告正文引用。

## 12. 无法解释差异时的提问机制

- 先检查OCR位数、单位、期间、期初期末、合并/单体及相关科目勾稽，能解释的必须在分析中说明变化来源和业务原因。
- 仍无法解释且会影响授信判断时，在工作版相应位置插入红色加粗问题，直接写清冲突数字和需要用户确认的事项；不要用“数据口径可能存在差异”等模糊句子带过。
- 用户确认后，用最终事实替换该问题并同步修改表格、财务分析、授信方案、担保分析和综合结论。除非用户明确要求保留，正式交付稿不得遗留未回答红字。
